# 小镇店铺：整组策划计划

这套文档按 GameDesignOS 的方式组织：先把已确认的决定和待确认的题目分开，每个题目单独谈完，由人确认后才写入策划总览。方法来源是 [GameDesignOS](https://github.com/DY-2026/GameDesignOS)。它的 7 个策划技能装在素材仓库根目录的 `.cursor/skills/`，只供这个项目使用。命令行工具不安装。

本阶段只完成整组策划。某一家店怎么操作、某一个系列的关卡规则，要等最后一份门禁通过，再为那个系列单独开窗口，并改用 [BMad Game Dev Studio](https://github.com/bmad-code-org/bmad-module-game-dev-studio) 写正式策划正文。

## 怎么开一个独立讨论

每个题目用一个新的 Agent 对话。每次都拖同一个文件：[现在做这个.md](现在做这个.md)。它会指出当前题目、该用哪个已安装技能，以及确认后要写回哪里。不要改拖 `讨论/` 里的单题文件，那个文件只在「现在做这个」指向它时才是当前题。

1. 新建一个 Agent 对话。
2. 把 `现在做这个.md` 拖进去。
3. 发送该文件里的那段指令。
4. 确认结论后，让该对话写回讨论稿、策划总览、计划表，并改写 `现在做这个.md` 指向下一题。
5. 放下这个对话。下一题仍拖 `现在做这个.md`。

## 这一阶段明确不写

- 某一关怎么操作，包括合成、三消、经营或别的玩法。23 号动物园先定完成时的样子和每日体力结构，操作留到那之后。
- 各场景的物品清单。等该应用的每日结构确认后再列。
- 安卓、苹果、微信、抖音、小红书的上架方式，以及下载、进度同步。这些最后再写。
- 系列和外形相近组。不在排表里定，开发某一个应用时再写回。
