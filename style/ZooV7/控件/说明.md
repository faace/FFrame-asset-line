# 控件槽

`ctrl.json` 的 `slots` 是这张图的名单。`rect` 是图集上的像素框，`display` 是显示尺寸（宽高各是图上的一半）。`sliced` 为 true 时按 `border` 做九宫格，四边顺序是左、右、上、下。`reserved` 为 true 的槽只占位，图上不画。

母版是 `history/v7/ui-sheet-v7.png`。下面的「对应」说的是母版上的哪一块。

## 已画

| 槽名 | 用途 | 对应母版 |
|---|---|---|
| `btn_primary` | 主按钮，草地绿 | 左列最上的绿按钮 |
| `btn_secondary` | 次按钮，奶油面，外圈里还有一圈浅橡木 | 左列第二条，奶油面木边 |
| `btn_warning` | 警示按钮，向日葵黄 | 左列黄按钮 |
| `btn_neutral` | 中性按钮，沙色 | 左列沙色按钮 |
| `btn_info` | 信息按钮，池塘蓝 | 左列蓝按钮 |
| `title_bar` | 弹窗标题木牌，两端各一颗铆钉，牌上没有字 | 右上那条长木牌 |
| `panel` | 面板。一圈浅橡木框，中间是奶油纸 | 标题下面的大方板 |
| `slot_item` | 物品格，中间是空的 | 方板右边的小木格 |
| `frame_select` | 选中框。外圈草地绿描边，浅橡木那圈是浅绿色，中间透空 | 小木格右边的绿框 |
| `tab_normal` | 未选中页签，下边是直的，方便和内容贴上 | 方板下面偏左的奶油页签 |
| `tab_selected` | 选中页签，草地绿，下边是直的 | 未选页签右边的绿页签 |
| `stepper_plate` | 步进器的数字底板，没有数字 | 页签下面的小木框 |
| `bar_bg` | 经验条背景。长木框槽，中间奶油 | 右列那条长的木框奶油槽 |
| `bar_fill` | 经验条填充。较粗的绿胶囊 | 长槽上面那条较粗的绿胶囊 |
| `slider_track` | 圆钮进度的背景。细的浅橡木条 | 圆钮左边那条细木条 |
| `slider_fill` | 圆钮进度的前景。细的草地绿条，上沿有浅高光。原名 `progress_fill`，游戏里一律用 `slider_fill` | 圆钮右边那条细绿条 |
| `slider_thumb` | 圆钮，奶油圆。夹在上面两条细条中间 | 两条细条中间的圆钮 |
| `icon_close` | 关闭，深绿叉 | 底行的叉 |
| `icon_help` | 帮助，浅橡木问号 | 底行的问号 |
| `icon_plus` | 加，草地绿 | 底行的加号 |
| `icon_minus` | 减。母版这个符号是红色，五色里没有红 | 底行的红色减号 |
| `switch_off` | 开关关掉。浅橡木胶囊，奶油圆钮在左。显示尺寸 96×48，不拉伸 | 母版上没有 |
| `switch_on` | 开关打开。草地绿胶囊，奶油圆钮在右。显示尺寸 96×48，不拉伸 | 母版上没有 |
| `checkbox` | 勾选框。浅橡木框，中间奶油，没有勾。显示尺寸 48×48，不拉伸 | 母版上没有 |
| `checkbox_mark` | 勾。草地绿，叠在勾选框上。显示尺寸 48×48，不拉伸 | 母版上没有 |
| `dropdown` | 下拉收起态的盒子。浅橡木框、奶油底。显示尺寸 320×72，九宫格 | 按面板那套画的 |
| `dropdown_list` | 下拉展开列表的底板。上边直、下边圆角，贴住盒子看不出缝。显示尺寸 320×64，九宫格上边为 0 | 母版上没有 |
| `dropdown_item_on` | 选中那一行的底板。草地绿圆角板。显示尺寸 320×64，九宫格 | 母版上没有 |
| `icon_arrow` | 下拉右侧箭头，下尖的 ∨。显示尺寸 44×44，不拉伸。展开时控件转 180° | 母版上没有 |
| `scrollbar` | 滚动条槽。细长木框、中间奶油。显示尺寸 32×160，九宫格 | 母版上没有 |
| `scrollbar_thumb` | 滚动条滑块。浅橡木胶囊，九宫格上下各 16，纵向拉伸圆头不走形。显示尺寸 32×64 | 母版上没有 |

圆钮这一组是三件：`slider_track` 是背景，`slider_fill` 是前景，`slider_thumb` 是圆钮。两条都是细条，绿的叠在木的上面当进度。`bar_bg` 和 `bar_fill` 是另一对长的经验条，不是这组。

开关是两张，圆钮画在图里。`switch_off` 是浅橡木，圆钮在左。`switch_on` 是草地绿，圆钮在右。不占 `checkbox`。

勾选框是两张。`checkbox` 是浅橡木框。`checkbox_mark` 是草地绿的勾，勾上才叠上去。不占 `switch_off`、`switch_on`。

下拉是四张：`dropdown` 收起态盒子、`dropdown_list` 展开列表底板（上边直角贴住盒子）、`dropdown_item_on` 选中行绿板、`icon_arrow` 箭头。滚动条是两张：`scrollbar` 槽、`scrollbar_thumb` 滑块（九宫格上下各 16，纵向拉伸时圆头保持原比例）。
