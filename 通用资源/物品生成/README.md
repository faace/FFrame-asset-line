# 物品生成

此目录是今后物品图片生成与后处理的统一工作区，适用于不同项目。2026-11-04从旧GameDesign的`通用资源/物品生成/`完整迁入FFrame-asset-line，原图、提示词、采用清单、脚本、后处理结果和旧版备份全部保留。

## 当前风格

已确认的第一套风格为ZooV7：明亮饱和、圆润粗像素、深橄榄棕粗描边、阶梯式明暗。母版为`物品批量-01-gpt-image-2.5-flare-v1.png`；第二批已使用第一批图片作视觉参考。后续延续这套物品时必须附上采用图片作风格参考，不能仅靠文字描述，也不要改回旧版细描边。其他风格应独立记录，避免混用。

## 工作方式

1. 维护物品清单，已满意项保留，不满意项与剩余物品合并到下一批。
2. 每批一张1024×1024联系表，通常4×4格；保留提示词、模型、视觉参考与原图。
3. 更新`物品采用清单.json`，抠图、裁切、居中、打包并检查实际64像素显示效果。
4. 按目标项目的约定同步PNG与plist，保留旧图备份和已有UUID。

## 当前文件

- `物品批量-01.md`、`物品批量-02.md`：提示词、批次内容与结果。
- `物品采用清单.json`：已采用的28个唯一槽位及来源。
- `已处理/`：28张透明单图、2048源图、1024游戏图集、plist、浅深底预览、检查报告和替换前备份。
- `试产第一批.mjs`：当前Cubence批次生成入口，`node 试产第一批.mjs 02`会重新生成第二批，注意不要覆盖已采用原图。
- `打包物品.mjs`：当前ZooV7专用打包入口；`node 打包物品.mjs --verify-synced`重建并检查同步结果。脚本依据自身目录定位输入，目录迁移后仍可运行。

当前打包脚本的输出规格及目标仍是`FFrame/assets/game/bundles/Skin/ZooV7/`，源图同步到`FFrame-asset-line/style/ZooV7/物品/`。这些是已接入项目的下游输出，不是今后物品生成的工作目录。其他项目接入时明确其目标路径后再同步。
