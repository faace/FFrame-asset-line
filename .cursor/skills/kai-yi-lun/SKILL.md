# 开一轮

用 Cursor 打开本仓库后，在 `/` 列表里选这一条。按下面的顺序做。每一步等人确认，确认前不生成下一张。

先读 `style/画风.md`。第一张效果图的风格参考是 `style/动物园效果图.v06.png`。不要读动物园工程的路径，不要用 Python。

## 生图

像素总数小于等于 1024×1204 的，用 `gpt-image-2.5-flare`，质量 medium。比这大的用 `gpt-image-2.5-flare-count`，质量 medium。超时就换一个新的输出路径再试，超时不算已经保存。密钥不进仓库。

效果图和开场背景是 1440×2560，走 count。

贴纸和场地先要透明底：`background` 为 `transparent`，`outputFormat` 为 `png`。切图脚本若报告没有可用透明通道，这一张改用品红 RGB(255,0,255) 重画再切。画布请求 1024×640；返回尺寸可以不同，以切出来的件为准，不因此改用品红。

输出都放在 `runs/<主题>/`。这个目录已 git 忽略。同一主题的目录已存在时，先问接着做还是新开一轮。不覆盖已经点头的效果图。

## 顺序

1. 问主题、大概做什么、有没有特别说明。
2. 没特别说明就锁住 `style/画风.md` 里的画风、镜头和外框。内部格局不锁。给出三套参考，等人选或改完再画：
   - 中央一座主建筑，四角四个分区，左中右中两座小店，南边拱门配售票和问讯，有游客和长椅。
   - 外框照旧，里面由主题决定。
   - 槽位同第一套，游客大约 18 到 24 人，椅子按儿童动物园 v03 来摆。
3. 效果图一次一张。人指出要改的地方就再出一张。点头后才画开场背景。
4. 开场背景一次一张。只留路、草地、树、花、外圈栏。房子、围栏、水池、动物、路灯、牌子、桌子、人都不画。参考图用已点头的效果图。点头后才拆区。树和花留在开场背景上，不进拆图清单。
5. 从效果图列出区域，人点一个区。列出这一区的清单再等人点头。清单含：中文名、英文文件名、效果图上的宽高、是否场地、朝向（一致 / 左右翻 / 前后另生）。场地只有地面会变才做。文件名英文小写加序号，场地文件名 `habitat.png`。区目录用英文 id。
6. 人点头才生成这一区。参考图只用效果图上这一区的裁切，不用上一张生成图。普通贴纸一类一张，件与件分开，无地面、无地面投影。描边约 1 像素，和效果图同一量级。提示词写死每一件的像素高。画大了在同一张 Sheet 上缩短再切，不把单件另缩。前后另一面单独生图。左右翻转不手改镜像，切完运行：

```bash
node scripts/flip.js <输入.png> --out <输出.png>
```

7. 切图：

```bash
node scripts/cut.js <sheet.png> --out <区id>/assets_png --names gate_01,sign_01
```

场地加 `--whole`，不把围栏和池子拆开。

8. 人可以在生成过程中直接改 PNG。改的是 Sheet，用改过的文件重新切、再量。改的是切好的件，用改过的文件重新量。人没叫重画，就不重画。

9. 量比例。倍数 = 效果图高度 / 切图不透明高度。同一区最大除以最小不超过 1.15。场地不进这组。不过关就改 Sheet 重画，不进入下一区。

```bash
node scripts/measure.js --manifest runs/<主题>/清单.json --zone <区id> --preview runs/<主题>/<区id>/拼接.png
```

10. 倍数过了，给人看贴回整张效果图的 PNG。人点头才进入下一区。不从 y=1800 裁。
11. 全部区做完后生成 HTML，页和动物园拼图预览一样：1440×2560，侧栏按区列表，按钮是「开场 · 施工中」和「完整」。底图是开场背景。施工牌是页面占位，不画进背景，主路不放牌。贴纸按效果图坐标贴，宽高同一个倍数。

```bash
node scripts/html.js --manifest runs/<主题>/清单.json
```

清单写在 `runs/<主题>/清单.json`。每件可有 `ref_wh`、`ref_box`（效果图上的 x,y,w,h）、`flip`（`none` / `lr` / `fb`）、`kind`、`z`、`placed`。区有 `id`、`name`、`site`、`board`。
